Optional short updates, one per JSON file. Copy `templates/content/news.json`.
Do not announce unpublished or embargoed work without public clearance.

Prepare real drafts and supporting internal notes outside the repository. Only
approved public records with `draft: false` belong here.

Follow the [news and events policy](../../docs/content-model.md#news-and-events-policy):
three homepage items in total, newest first; 80 words, two resource links, and
three credited photographs per update. Only the first photo appears on the
homepage. Older updates keep their individual pages. Use `endDate` only for a
verified event range, otherwise null. `photos` can be an empty array.
